# 프로젝트 맥락 (Copilot에게 주는 자료)

이 파일은 사람이 조사한 사실과 팀 결정을 정리한 자료다. 코드와 PRD/TRD는 이 자료를 근거로 새로 작성한다.

## 1. 대회
- 청도 바이브코딩 해커톤, 2026-11-05, 제출 마감 16:30 (15:00 1차 자동 검수)
- 주제: 개인 생산성 향상 웹앱. 필수: GitHub Copilot SDK + Microsoft Agent Framework, Azure 배포
- 제출: 팀장 **개인 계정 공개 저장소**, 루트에 `PRD.md`·`TRD.md`, 커밋 해시, Azure 기본 도메인 URL
- 로그인 없이 핵심 기능 사용 가능해야 함 (막히면 전 항목 1점)
- 최대 2회 제출, **나중에 낸 점수가 최종 점수**
- 허용 도구: VS Code + GitHub Copilot, Copilot CLI, Copilot 앱
- 규칙 원문: https://github.com/hackersground-kr/hackathon-cheongdo

## 2. 평가 기준 (AI 심사 에이전트 7개 항목)

## 3. 발표 요점 (MS 수석 디벨로퍼)
- 3층 구조: Agent Framework(AI) · MCP 서버(도구) · Aspire(인프라)
- 예시: React 웹 ↔ AG-UI ↔ 에이전트 서비스 ↔ MCP 서버, 전문 에이전트 여러 개 + AI Judge 에이전트
- 배포: `az login` → `aspire deploy` → Azure Container Apps (자동 확장, Scale-to-Zero), `aspire destroy`로 정리
- 다중 에이전트 패턴: Sequential, Concurrent, Handoff, Group Chat(작업자↔검토자), Magentic
- 인스트럭션: 역할, 바운더리, 단계, 도구 사용법, 말투, 상태 확인. 데이터에 없는 값을 만들지 않고 evidence를 함께 출력
- 결과 이유를 보여 주고, 다른 모델로 검증
- 문서: AGENTS.md, PRD(무엇) · TRD(어떻게) · TDD(왜). 간결·명확하게, 국립국어원 규범
- 스킬: https://github.com/justinyoo/skills (create-prd, create-trd, create-tdd, korean-technical-writing)

## 4. 아이디어 (팀 검토 중)
**청도 새내기 농부 비서 (가칭)**: 청도의 청년·귀농 1~3년 차 농부용.
- F1 말로 쓰는 영농일지: 음성·글 → 날짜·밭·작업·시간·농약 사용으로 정리, 확인 후 저장
- F2 오늘 할 일: 날씨·병해충 정보를 동시에 조회해 근거 붙은 할 일 제안, 승인한 것만 저장
- F3 청년농 지원사업 비서: 프로필·일지로 해당될 수 있는 사업, 조건, 서류, 마감 정리 ("해당될 수 있음/확인 필요"로만 표시)
- F4 계절근로자 일손 관리: 근로자별 근무 기록, 작업 지시 번역(한국어·영어·필리핀어), 체류·보험 체크리스트. 별칭만 저장, 위반 판정 안 함
- F5 사진으로 작물 증상 확인: 특징 서술 → 후보 최대 3개·근거·확신 정도 → 일반 관리 안내. 약제명·희석 배수 처방 안 함
- 공통: 로그인 없는 시연 프로필, AI 결과 표시, 저장 전 승인, 근거 표시
