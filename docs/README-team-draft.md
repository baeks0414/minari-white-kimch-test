# 미나리 백김치 — 청도 새내기 농부 비서 (가칭) 초안 묶음

작성: 2026-11-05 11시 30분 (HS 정리). 팀 검토용 초안이다.

## 한 줄 소개
청도의 청년·귀농 농부가 말로 영농일지를 남기면, AI 에이전트가 일지 정리 → 오늘 할 일 → 지원사업 → 계절근로자 관리까지 이어 준다.

## 꼭 알아야 할 대회 규칙
- 제출 저장소는 **팀장 개인 계정의 공개 저장소**만 가능 (조직 저장소 불가)
- 루트에 `PRD.md`, `TRD.md` 필수. 심사는 이 두 문서와 실제 앱 동작으로 한다
- 로그인 없이 핵심 기능을 쓸 수 있어야 한다 (막히면 전 항목 최저점)
- 2회 제출 가능, **나중에 낸 점수가 최종 점수**
- 코드는 GitHub Copilot으로만 작성 (타사 AI 코딩 도구 금지)
- 마감 16:30, 15:00 1차 자동 검수

## 팀이 정할 것
1. 에이전트 서비스 언어: Python 또는 .NET
2. 배포: Aspire + Container Apps (발표 권장) 확정 여부
3. 공공데이터포털 인증키 신청 담당 (기상청 단기예보, 농촌진흥청 병해충 예찰정보, 공공서비스(혜택) 정보)
4. 오늘 만들 범위: F1~F4 전부 vs F1~F3 먼저

## 실제 데이터 원칙
- 날씨·병해충·지원사업은 실제 공공 API를 실시간으로 쓴다.
- API가 실패하면 `seed/`의 실데이터 스냅샷을 쓰고, 화면에 기준 시각과 출처를 보여 준다.
- 가상 데이터는 시연 농부 프로필, 영농일지, 근로자 별칭뿐이다.
