# PLAN — 청도 퀘스트 (관광지 리워드)  · data-app="quest"
주제 문장: 청도 퀘스트는 [주제어]를 여행 퀘스트로 푸는 서비스다.  ← 당일 수정

## 문제 → 해결 → 효과 (PSST)
- 문제: 방문은 있는데 지역에 돈과 의견이 남지 않는다 (생활인구 34.4만, 관광주민증 혜택 이용 1.2%)
- 원인: 다음에 갈 곳, 지역에서 쓸 이유, 의견을 낼 창구가 없다
- 해결: 퀘스트로 동선을 만들고 → 포인트를 특산품으로 교환하고 → 빈 공간 현장에서 제안을 받는다
- 효과: 1인 방문 장소 수·특산품 교환 증가, 군은 AI가 정리한 제안을 받는다

## 화면 (라우트)
| 라우트 | 화면 | 핵심 |
|---|---|---|
| / | 시작하기 | 닉네임 가입 폼 |
| /maps | 맵 선택 | 위치 기준 정렬, 맵 카드 |
| /maps/:id | 퀘스트 지도 | 핀(관광=오렌지, 제안=하늘), 모의 위치, 목록 |
| /quests/:id | 관광 퀘스트 | 도착(GPS·코드)→사진(파일·건너뛰기)→퀴즈 |
| /proposals/:questId | 미래 제안 | 공간 정보 카드, 글·대상, AI 정리 |
| /store | 스토어 | 특산품 교환권 교환 |
| /me | 마이페이지 | 포인트 내역, 스탬프, 내 제안, 보관함 |

## 데이터 (seed/quest.json)
regions · places(lat,lng,code) · quests(type tour|proposal, missions[]) · products · users · checkins · proposals · redemptions · pointLogs

## 핵심 로직 (서버)
- F-06 haversine 거리 ≤ 100m 이면 도착 (또는 장소 코드 일치, 또는 mock)
- F-14 같은 user·quest·날짜 인증 1회
- F-21 포인트 잔액 ≥ 가격일 때만 교환, pointLogs 합 = 잔액
- 포인트: 도착 50 · 사진 50 · 퀴즈 50 · 제안 300 · 맵 완주 200

## AI 기능 (1개)
제안 글 → { title(한 줄), tags[분야], target } JSON, 비슷한 제안 묶기(태그 겹침)

→ 평일 소싸움장 제안 작성 → AI 정리 → +300P → 스토어 감말랭이 한 봉 교환권(400P) → 마이페이지 확인
