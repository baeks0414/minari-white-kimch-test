# PLAN — 청도 시네마 (소싸움장 + 빈 공간 상영)  · data-app="cinema"
주제 문장: 청도 시네마는 [주제어]를 비어 있는 공간의 상영으로 푸는 서비스다.  ← 당일 수정

## 문제 → 해결 → 효과
- 문제: 큰 공간이 비어 있다 — 상설 소싸움경기장은 토·일만 경기, 평일 5일 비어 있음(돔, 약 1만1천 석)
- 원인: 평일에 이 공간을 쓸 프로그램과 예약 창구가 없다
- 해결: 평일 저녁 상영 회차를 만들고 → 좌석·코스(상영 + 와인터널·숙소)를 한 번에 예약 → 빈자리는 AI가 추천으로 채움
- 효과: 평일 공간 가동, 체류 시간 증가(상영 후 숙박·식사)

## 화면 (라우트)
| 라우트 | 화면 | 핵심 |
|---|---|---|
| / | 시작하기 | 닉네임 가입 |
| /schedule | 상영 시간표 | 날짜 × 상영관, 회차 카드 |
| /sessions/:id | 회차 상세 | 작품·장소·남은 좌석, 지도 |
| /book/:id | 예약 | 인원, 코스 추가(와인터널·숙소), 금액 계산 |
| /tickets | 내 티켓 | 예약번호·코스 일정 |
| /recommend | AI 추천 | 남은 시간·취향 → 빈자리 회차 3개 |

## 데이터 (seed/cinema.json)
venues(lat,lng,seats) · films · sessions(venueId, filmId, start, seats) · bookings(sessionId, people, addOns[], amount, status)

## 핵심 로직 (서버)
- 남은 좌석 = seats − 예약 인원 합, 0 이하면 409
- 같은 사람 시간 겹치는 회차 예약 금지
- 금액 = 회차 가격 × 인원 + 코스 추가 금액 (서버에서 다시 계산)

## AI 기능 (1개)
"오늘 저녁 2시간, 가족 4명" → 빈자리 많은 회차 + 이동 시간 고려 추천 3개 JSON

## 데모 시나리오
닉네임 → 시간표 수요일 → 소싸움장 19:00 회차 → 4명 + 와인터널 코스 → 예약 확정 → 내 티켓 → AI 추천 보기
