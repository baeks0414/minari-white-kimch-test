# PLAN — 청도하숙 (시골 하숙집 예약 + 편지 후기)  · data-app="hasuk"
원본: 노션 '서비스 기획 - 청도하숙 웹' (수희 님). 아래는 개발용 요약.
주제 문장: 청도하숙은 [주제어]를 빈집·주민 호스트·숙식 예약으로 푸는 서비스다.  ← 당일 수정

## 문제 → 해결 → 효과
- 문제: 남는 집(빈집 502호, 1등급 151호)·일할 주민·찾아오는 사람이 있지만 묶어 줄 숙박 상품이 없다
- 원인: 숙소·식사·교통을 따로 찾아야 하고, 청도 숙소는 풀빌라 위주
- 해결: 방 + 조식 + 픽업 + 호스트를 한 번에 예약, 떠날 때 편지 후기
- 효과: 빈방·빈집 가동, 주민 호스트 소득, 편지로 재방문

## 화면 (라우트)
| 라우트 | 화면 | 핵심 |
|---|---|---|
| / | 홈 | 날짜·인원, 추천 3채 |
| /houses | 목록 | 면 필터, 카드(호스트 한마디·가격·대표 편지) |
| /houses/:id | 상세 | 호스트·아침상·방·편지함 |
| /book/:houseId | 예약 | 체크인·아웃(최대 14박), 인원, 픽업, 금액 |
| /book/:id/pay | 결제 방법 | 현장 결제 / 계좌이체 → 확정 (실제 결제 없음) |
| /book/:id/done | 완료 | 예약번호·일정 카드·편지 쓰기 |
| /letters/new | 편지 | 편지지 5종, 감 평점, 500자, 사진 1장 |

## 데이터 (seed/hasuk.json)
houses · hosts · bookings(status pending→confirmed) · letters(paper 1~5, rating 1~5, body ≤500)

## 핵심 로직 (서버)
- 금액 재계산 = 1박 가격 × 박수 × 인원 (+ 픽업)
- 같은 집 날짜 겹침 409, 최대 14박
- 편지: 예약 있는 사람만, 500자·평점 1~5·편지지 1~5 검사

## AI 기능 (1개, 확장 후보)
"차 없이 둘이 조용한 곳" → 조건에 맞는 하숙집 3채 추천 JSON (시간 남을 때만)

## 데모 시나리오
홈 → 금요일 2명 → 각북면 '순자네 하숙' → 1박 + 청도역 픽업 → 현장 결제 → 일정 카드 → 미나리 편지지·감 5개로 편지 → 편지함
